# 📊 Interactive Data Analysis Dashboard

A dynamic web application built using **R** and **Shiny** to explore, analyze, and visualize datasets interactively. This project bridges the gap between statistical 
analysis and web application development.

## 🚀 Features
* **Interactive Data Visualization:** Dynamic plots and charts generated using `ggplot2`.
* **Statistical Summary:** Real-time calculation of descriptive statistics.
* **User-Friendly UI:** Clean interface designed for seamless data exploration and filtering.

## 🛠️ Tech Stack
* **Language:** R
* **Framework:** R Shiny
* **Libraries:** `shiny`, `ggplot2`, `dplyr`
